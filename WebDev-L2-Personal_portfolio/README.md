# Personal Portfolio Website

## Project Overview

This project is a personal portfolio website created to showcase my
introduction, skills, projects, and contact information.

The portfolio provides a simple and clean interface where visitors
can learn about my technical skills and explore my projects.

## Technologies Used

- HTML5
- CSS3
- Google Fonts

## Features

- Responsive navigation bar
- Home/Hero section
- Personal introduction
- About Me section
- Skills section
- Projects section
- Contact section
- Email, LinkedIn and GitHub links
- Responsive and clean layout

## Skills Showcased

- HTML5
- CSS3
- JavaScript
- Java
- C Programming
- SQL
