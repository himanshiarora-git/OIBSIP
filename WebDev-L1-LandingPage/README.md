# PureGlow Soap Company Landing Page

## Project Overview

PureGlow is a responsive static landing page designed for a natural and handcrafted soap company.

The website focuses on a clean, modern and nature-inspired design to present the brand, its benefits and customer experience.

## Technologies Used

- HTML5
- CSS3

## Features

- Sticky navigation bar
- Hero section with headline, description and CTA button
- Benefits/Features section
- About section
- Customer testimonial section
- Footer with contact and social links
- Responsive design for desktop, tablet and mobile
- CSS Grid and Flexbox for layout
- Consistent colour palette
- Clean and readable typography
